# Dashboard de Vendas — Xbox

## Sobre o projeto
Dashboard de vendas desenvolvido em Excel como parte do bootcamp Santander/DIO.
O projeto tem como objetivo transformar dados brutos de vendas em informações visuais que facilitem a análise do desempenho e apoiem a tomada de decisões.

## Objetivo
Organizar e visualizar os dados fornecidos pela DIO, transformando-os em indicadores e gráficos interativos.

## Dados utilizados
A base utilizada neste projeto foi disponibilizada pela DIO como parte do desafio.
